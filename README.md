# RNSIT MUN Website Redesign

> **Live Demo:** [remun-ten.vercel.app](https://remun-ten.vercel.app/)

---

## 📌 Project Overview

This project is an unofficial website redesign created as an interview submission / recruitment task for the **RNSIT Model United Nations (MUN)** team.

It showcases an editorial, diplomatic design direction, responsive layout, and modern frontend implementation for the conference homepage.

> **Disclaimer:** This is purely a design concept and technical demonstration prepared for the interview. It is not the official conference portal.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Animations:** Motion & GSAP
- **Icons:** Lucide React

---

## 🚀 Getting Started

To run this project locally:

1. Clone or download the repository:
   ```bash
   git clone <repository-url>
   cd REMUN
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
